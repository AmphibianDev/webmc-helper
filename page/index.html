  1. Name it exactly WebMC Helper and save. The first run asks you to allow scripts once: Shortcuts → Settings → Advanced → Allow Running Scripts.

      Where everything lives

      On your computer: nothing, once the session ends. The helper downloads the game into one throwaway directory under /tmp, starts the real Java client with Fabric, and then deletes that directory — the client, the assets, the Java runtime, its own log.

      In this browser: your world, your mods and your settings. That is what makes the game disposable and the computer untouched. It is stored with this page's own storage, is never uploaded anywhere, and clearing site data removes it.

      What this page can and cannot do: it cannot start a program, read a file, or see /tmp. The helper does that part. This page asks it to, watches the log, and keeps what the session produced.
