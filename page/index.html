      Where everything lives

      On your computer: nothing, once you close this session. The helper downloads the game into one throwaway folder under /tmp, starts the real Java client with Fabric, and then deletes that folder — including the client, the assets, the Java runtime if it fetched one, and the logfiles. There is no service, no folder in your home directory, nothing to uninstall.

      In this browser: your world (saves, screenshots, options, crash reports) and your mod jars. That is deliberate — it is what makes the game disposable and the computer untouched. It is stored with the browser's own storage for this page, is never uploaded anywhere, and you can delete it by clearing site data.

      What the page can and cannot do: it cannot start a program, read a file, or see /tmp. The helper does that part. This page only asks it to, watches the log, and keeps what the session produced.
